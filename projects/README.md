# Resume Projects

This directory contains the two defensive security projects described in the resume.

- [Keylogger Detection System](keylogger-detection/README.md): process-metadata monitoring and explainable heuristic alerts. It never captures keystrokes.
- [Phishing Website Detection using ML](phishing-detection/README.md): static URL feature extraction, Random Forest demo model, Flask API, and dashboard.

Both are educational prototypes. Read each project README for limitations, safe-use notes, setup, and tests. Synthetic demo data and heuristic detections must not be represented as validated production performance.
