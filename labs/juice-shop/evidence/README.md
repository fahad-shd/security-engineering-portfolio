# Evidence index

Store only screenshots and notes that you personally captured from your local Juice Shop lab. This repository intentionally contains no fabricated screenshots or claimed findings.

## Naming convention
YYYYMMDD-HHMM-AREA-NN.ext

Examples:
- 20261114-1430-HEADERS-01.png
- 20261114-1445-COOKIE-FLAGS-01.png

## Before committing evidence
- [ ] Remove passwords, session cookies, bearer tokens, API keys, and authorization headers.
- [ ] Remove personal data and unrelated browser tabs or notifications.
- [ ] Keep only the minimum request/response context needed to support the finding.
- [ ] Confirm the evidence came from your local 127.0.0.1 Juice Shop instance.
- [ ] Link each evidence item to a finding or report section.
- [ ] Do not upload raw proxy history, browser profiles, or full traffic captures.
